# Python Roguelike

A complete, playable roguelike dungeon crawler written in Python and Pygame.

## Features
- **Procedural Dungeons**: Explore infinite variations of dungeon floors.
- **Tactical Combat**: Directional attacks, stamina management, and guarding.
- **Crafting System**: Scavenge materials and craft items.
- **Real Sprites**: Pixel-art visuals generated procedurally.
- **Progression**: Deep itemization and enemy variety.

## Installation

Requires Python 3.10+ and Pygame.

```bash
pip install pygame
```

## How to Run

From the root directory:

```bash
python -m roguelike.main
```

## Controls

- **WASD**: Move
- **SPACE**: Wait
- **F**: Attack Mode (Then WASD to strike)
- **Z**: Toggle Guard
- **G**: Pickup Item
- **I**: Inventory (1-9 to use/equip)
- **C**: Crafting (1-9 to craft)
- **ENTER**: Use Stairs / Next Level
- **ESC**: Save & Quit
